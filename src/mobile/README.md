# 移动端模块

`src/mobile` 负责窄屏和触控环境，不改动 Matrix 业务逻辑。手机、窄屏，或打开 `/?mobile=1` 时生效；`/?mobile=0` 强制桌面布局。

## 文件

- `detect.js`：判断是否进入移动端布局（窄屏、粗指针，或 `?mobile=1`）。
- `viewport.js`：键盘高度、安全区和左缘滑动返回。
- `gestures.js`：长按打开消息操作，左滑进入多选，替代桌面右键/悬停。
- `styles.css`：单栏分屏、底栏表单、44px 触控区和溢出约束。
- `index.js`：安装移动端视口、手势和历史栈。

`app.js` 只在移动端切换房间列表 / 会话 / 详情三层视图，桌面三栏布局保持不变。

## 交互

- 编辑器按微信：无格式工具栏；键盘回车换行，点「发送」才发消息。
- 加号弹出相册、拍摄、文件；表情面板在编辑器下方，分类可左右滑动，和键盘互斥。
- 长按输入框进入按住说话，松手发送，上滑取消。
- 消息三个点打开底部操作（复制/回复/转发等），点空白收起；表情回应走单独入口。
- 输入框上方显示「xxx 正在输入…」。
